# 前端开发规范

版本：V1.0 · 规则前缀：FE。

## 1. 工程复用

FE-01：使用固定版本 管理后台（基于 Vben v5.7.0） 与 Element Plus。先检查已有表格、表单、Modal／Drawer、权限指令与请求封装，再创建组件。业务逻辑放 apps/admin-web，不把客户偏好散布到 @vben/*。

后端动态菜单采用构建时已知组件映射，不执行远程组件代码。路由可见不代表 API 可访问；按钮隐藏只改善体验。

## 2. 页面组成

列表页负责筛选、分页、选中记录、加载状态及调用 API；字段 schema 管理列和表单展示；本模块表单组件管理编辑状态；API 文件管理请求方法和契约类型。

不在模板中拼复杂业务表达式，不在每个组件重新实例化 HTTP 客户端。模块仅使用与当前需求相关的共享状态；临时表单不塞到全局 store。只有多处实际复用且语义相同才抽公共组件。

## 3. 请求与响应

FE-02：从生成 OpenAPI 类型取请求／响应结构，不复制 Entity 接口。统一请求层只解包一次，二进制下载使用专用配置。GET 请求取消／过时响应不得覆盖新筛选结果，可使用请求序号或取消机制。

Access 在内存；刷新单入口合并，同标签与跨标签协调；只对 AUTH_ACCESS_EXPIRED 续期一次。401 撤销、403 无权、409 冲突和 503 依赖错误分别处理，禁止对所有错误统一登出。

非幂等写入不能在拦截器自动重放，除非沿用同一个 Idempotency-Key 且服务端支持安全重试。超时不等于失败，创建／确认操作进入“结果待确认”并查询结果。

## 4. 字段与表单

FE-03：ID 和 DECIMAL 原样字符串，不以 Number 绑定下拉 ID，不按金额浮点计算。显示格式与提交值分离。纯日期组件提交 YYYY-MM-DD，不自动 toISOString；时刻输入按明确项目时区转换成 UTC。

创建与编辑共享字段组件但使用独立请求类型；编辑携带 version。只提交允许字段，部分更新 未修改不传；清空只对 nullable 字段提交 null。密码不自动 trim，不保存到状态持久化或浏览器存储。

表单提交中禁用重复点击，失败保留内容。后端 fieldErrors 映射到字段；前端校验只用于体验，不能代替后端规则。409 保留输入并提示重新加载，不自动覆盖为新 version 后重新保存。

## 5. 标准状态

| 场景 | 展示与行为 |
|---|---|
| 首次加载 | 局部 loading，避免显示“暂无数据”闪烁 |
| 空结果 | 空状态，可保留新增／调整筛选入口 |
| 无权限 | 明确提示，无继续请求循环 |
| 加载失败 | 错误状态与重试，不把旧结果标成最新 |
| 写入中 | 防重复，重要流程可提示离页 |
| 成功 | 服务端结果确认后反馈，合理刷新当前列表 |
| 结果待确认 | 显示查询／重试原操作结果的动作 |
| 冲突 | 保留用户输入，提示重新读取 |

FE-04：批量仅作用于明确选中的 ID 与 version；筛选变化后清理失效选择，不默认跨全部分页全选。删除确认显示对象、影响和引用限制，不能把危险操作埋在无确认的通用按钮里。

## 6. 文件和任务

上传完成仅取得临时 fileId，表单保存后才形成业务关联。取消表单不直接删除已被其他对象引用的物理文件。

导出点击后显示 taskId 和状态入口，可离开页面。轮询有间隔、退避和终态停止；页签后台或离页可暂停。失败、过期、撤权分别解释，下载按钮禁用后后端仍须独立拒绝。

导入支持模板版本、预检错误行、确认、提交状态和结果查询；有错误禁止确认，不允许前端把“正确行”自行拼回请求绕过原文件校验。

## 7. 缓存与体验

FE-05：实例标识隔离本地偏好、路由标签与缓存；退出／切换账号清理用户信息、动态路由、查询缓存与未授权页面。不得将客户业务列表和 Token 持久化以“离线体验”名义扩出未设计的数据存储。

统一键盘可达、表单标签、焦点与错误反馈；加载过程不遮挡必要的退出和恢复入口。主题沿用框架能力，品牌主色按平台配置，不擅自套用其他项目颜色规范。

中文文案按现有 i18n 结构管理；不宣称已完成其他语言。移动端／PDA 客户端不在本 PC 后台模块规范中隐含实现。

## 8. UI／UX 与技能检查

FE-06：新页面和界面改版遵循 [管理后台 UI／UX 规范](ui-ux.md)，按 AI.md 第 12 节应用设计、Vue 实现与界面审查技能。信息层级、token、交互状态和实际浏览器验证均属于交付内容；不得靠默认圆角、渐变和卡片套用同一视觉模板。规则与上游技能示例冲突时，保留项目固定栈、命名、精度与契约。
