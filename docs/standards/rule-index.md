# 核心规则检查索引

规则是实施目标，以下“检查”说明应如何验证，不代表当前仓库已经实现自动检查。

| 规则 | 必须满足 | 实现位置 | 检查方法 |
|---|---|---|---|
| ENG-01 | 固定技术与依赖 | package.json、锁文件、依赖基线 | frozen 安装＋容器构建 |
| ENG-02 | Entity 集中且无循环 | database 实体和注册清单 | 边界检查＋真实迁移 |
| ENG-03 | apps 到业务到基础依赖方向 | 包依赖／公开入口 | lint／依赖图＋人工表归属检查 |
| ENG-04 | strict、无掩盖错误 | tsconfig、lint、源代码 | typecheck、lint、审查 |
| ENG-05 | 目标命令真实执行并传递失败 | scripts、CI | 故意注入失败验证阻断 |
| API-01 | 业务方法仅 GET／POST；DTO→OpenAPI→生成类型单向 | DTO、生成工具与产物 | 路由／前端／OpenAPI 方法白名单检查；临时生成比较，无手改 |
| API-02 | JSON 封装／错误分支一致 | Interceptor、Filter、客户端 | 200／400／401／409／503 契约测试 |
| API-03 | 分页／排序／选项受限 | Query DTO、查询层 | 越界、非法字段、total 范围 |
| API-04 | 未知字段、null／未传区分 | DTO、全局管道 | DTO 与真实请求否定测试 |
| API-05 | 幂等防同键不同请求 | 幂等协调与唯一约束 | 并发、同键异摘要、撤权重放 |
| DATA-01 | ID／金额字符串、UTC／日期分离 | 驱动、映射、前端 | 大整数与精度／跨时区往返 |
| DATA-02 | 唯一、归属、逻辑删除明确 | 模块设计、Entity、DDL | 并发唯一、软删重复与索引检查 |
| DATA-03 | 同事务 Manager／审计 | 应用 Service 与公共 Provider | 审计失败回滚真库测试 |
| DATA-04 | 范围＋version 条件写入 | Query／Service | 两人并发、越权、批量失败原子性 |
| DATA-05 | Migration 不改历史 | 迁移目录、发布清单 | 校验和、空库／升级、恢复 |
| BE-01 | 传输／用例／查询职责分开 | Controller、Service、Query | 审查与模块测试 |
| BE-02 | API 默认保护、权限声明 | Guard、权限注册 | 路由声明检查＋直接越权请求 |
| BE-03 | 每操作独立范围 | Scope Policy、查询层 | 全量查看＋本人修改组合 |
| BE-04 | 更新／删除／转移原子 | Service、事务 | 冲突、锁顺序、epoch |
| BE-05 | 错误保留失败语义 | Filter、Service、日志 | DB 故障不返回空成功 |
| FE-01 | 复用框架、限制上游改动 | admin-web 应用适配 | diff 审查＋构建 |
| FE-02 | 单次解包与受控重试 | 请求封装 | 401 分支、超时、原键重试 |
| FE-03 | 表单精度与 部分更新 正确 | schema、表单、API | 空／null／未传与409页面验证 |
| FE-04 | 状态明确、批量选择明确 | 页面容器 | 筛选变化、失败、禁用与重试 |
| FE-05 | 实例和账号缓存隔离 | store、路由、偏好 | 切账号／跨实例验证 |
| FE-06 | UI 任务按技能与本地视觉规范执行 | AI.md、ui-ux.md、UI 文件 | 设计说明、范围内审查与实际页面检查 |
| UI-01～03 | 任务导向布局，统一 token，避免无意义装饰 | 页面布局与样式 | 页面信息层级、组件与脱敏截图审查 |
| UI-04 | 状态、表单、键盘和焦点完整 | 页面、表单、弹窗／抽屉 | 正常／错误／空／无权限、键盘与长内容检查 |
| UI-05～06 | Vue 职责与类型明确，优化有依据 | 组件、schema、composables、API | Vue 规范审查、lint、类型与必要性能检查 |
| UI-07 | 代码、交互与视觉结论有实际证据 | 浏览器、检查结果、必要截图 | 按影响验证，未验证项明确记录；不声称已有自动审美门禁 |
| SEC-01 | 会话安全与秘密隔离 | auth、配置、日志 | 撤销、轮换竞争、secret scan |
| SEC-02 | 授权变化使旧导出失效 | 安全状态与完成／下载 | 排队／执行中撤权真库测试 |
| SEC-03 | 文件依据业务关联授权 | file 与业务引用服务 | 猜 ID、他人临时文件、清理竞争 |
| JOB-01 | 导入隔离、整批与复检 | import 解析／确认 | 压缩炸弹、重复、超时与断网 |
| JOB-02 | MySQL 真源、可靠投递 | task、dispatch、投递器 | 入库后队列宕机、先消费后回写 |
| JOB-03 | 单一重试权威与执行隔离 | Worker、租约、attempt | 失租旧执行、重复消费和重启 |
| JOB-04 | 队列与文件运行隔离 | Compose、Valkey、清理任务 | 持久化、内存策略、跨实例隔离 |
| QA-01 | 风险对应测试 | 测试矩阵 | 不以覆盖率数字替代风险验证 |
| QA-02 | 测试库多重保护 | setup、CI 配置 | 正式目标拒绝、隔离目标允许 |
| QA-03 | CI 检查有真实阻断 | CI、脚本 | 引入故障确认非零退出 |
| QA-04 | 已实现／已验证／已发布区分 | PR、验证报告 | 证据与结论逐项对应 |
| REL-01 | 发布单元与恢复路径一致 | 清单、迁移、镜像 | 定制升级与部分失败演练 |
| REL-02 | DB＋文件一致备份 | 停写流程、备份集 | 引用、哈希、业务抽样与恢复 |

AI.md 为执行规则，不另编号复制上述条款。规范变更时同步索引；模块实现时关联相关规则与 V1.0 的验收编号。新模块不需要把整个索引再复制一遍。
