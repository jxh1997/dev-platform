# ADR-003：固定来源的管理后台通用交互恢复

状态：已实施。日期：2026-11-11。

继续使用 ADR-001 固定的 Vben Admin v5.7.0，不升级依赖。按用户确认，本次恢复前端通用交互，站内消息后端留待后续实现。

应用层在 `apps/admin-web` 装配登录工具栏、个人中心、时区、通知空状态和锁屏插槽。登录页保留 DevPlatform 中性视觉，支持居左、居中、居右；账号登录接真实认证接口。记住账号按应用命名空间和 Origin 隔离，仅保存账号。短信、扫码、第三方认证和公开注册没有外部服务或业务契约，不展示可用入口。

## 必要的底座补丁

- preferences：初始化采用“显式应用约束 > 用户缓存 > 默认值”，修复缓存被完整初始对象覆盖。认证模式、实例名称等显式约束保持优先；未锁定的主题、布局等允许恢复。
- preferences-button：绑定抽屉打开事件；设置开关补标签关联与真实 disabled；主题／布局预设改用可键盘操作的按钮。
- authentication/login：可传账号存储键，存储不可用时仍可登录，防止验证期间重复提交；不保存密码。
- IconButton：显式将 attrs 传给实际按钮，修复有 Tooltip 时 aria-label 等属性丢失。
- Popover：增加可选 triggerAsChild，内容与触发器并列；通知入口使用单个按钮，避免嵌套按钮及重复切换。
- FullScreen：沿用 VueUse 浏览器全屏，增加支持状态、可访问名称和失败反馈。标签页内容最大化与浏览器全屏各自保留原行为。
- 搜索、标签工具、时区、用户菜单及解锁入口：补按钮语义或可访问名称；用户快捷键始终注册、按当前偏好判断是否执行，修复运行中开关不生效的问题；不引入新依赖。

前述补丁不包含业务权限条件。应用首次启动使用单次 `shell-capabilities-v1` 标记，将旧缓存中此前被强制禁用的通知、锁屏入口恢复；保留其他偏好，之后用户关闭入口的选择照常持久化。

## 安全与边界

锁屏仅是当前页面的临时遮罩，口令随内存清除，刷新不保持锁定，不作为安全退出或服务端鉴权手段。返回登录调用真实退出接口；服务端授权继续独立执行。Access Store 仍不持久化 Token、权限或锁屏口令。

通知弹层和消息中心展示真实空状态，不调用不存在的消息接口，不创建演示通知。后续建设消息后端时再定义权限、已读／删除语义与实时更新契约。

功能范围、浏览器验证与截图见 [通用交互验证报告](../verification/2026-11-11-admin-shell.md)。本次不声称与在线演示站当前版本逐像素或全功能等同。

后续按用户指定的演示登录页参考，登录外壳改为复用固定来源 AuthPageLayout 与原有插画；AuthenticationLogin 增加验证码插槽，SliderCaptcha 增加普通拖动模式的键盘／可访问语义。服务端登录校验边界与验证证据见 [登录布局与滑块验证](../verification/2026-11-11-login-slider.md)，覆盖本 ADR 原登录外壳视觉取舍。
