# 管理后台前端通用交互恢复

目标：按用户确认，恢复固定 Vben v5.7.0 的前端通用交互；站内消息后端与外部登录服务后续接入。本次不修改认证接口、权限、数据库或生产部署。

## 已确认的差异

- 偏好按钮没有绑定打开抽屉事件；偏好初始化用完整初始值覆盖缓存，导致主题、布局等刷新后丢失。
- 登录页面未接入登录布局切换，记住账号关闭；自有登录外壳忽略 authPageLayout。
- 通知与锁屏被应用配置禁用，BasicLayout 缺少通知及锁屏插槽，个人菜单只有改密。
- 全屏组件已有实现，但没有可访问名称与不支持时的反馈；需实际验证浏览器全屏和标签页内容最大化。

## 实现边界

1. 偏好管理仅修复通用合并顺序：显式应用约束 > 用户缓存 > 底座默认；认证模式等项目约束不允许缓存覆盖。
2. 修复底座偏好按钮打开事件；应用继续复用原偏好抽屉，验证外观、布局、快捷键、重置和刷新保持。
3. 登录外壳由应用维护中性视觉，支持左／右／居中三种布局、主题和偏好入口；记住账号按实例命名空间与 Origin 隔离，仅保存账号，不保存密码或 Token。
4. 应用布局补齐 Notification、TimezoneButton 和 LockScreen 插槽，个人菜单加入本人会话；消息弹层和查看全部抽屉均为空，不生成假数据或伪造 API。
5. 锁屏仅为当前页面的临时遮罩，锁屏口令只在内存，保留现有服务端认证边界；返回登录走真实退出。
6. 全屏沿用 VueUse／底座组件，补可访问名称与受支持状态。原标签页、全局搜索、面包屑、刷新、语言、时区按实际支持验证，不新增重复实现。

## 验证与交付

- 为偏好缓存恢复及应用约束保留添加单元回归；类型、lint、构建检查覆盖修改源文件。
- 独立 13307 测试库、5778 Web／4311 API 的 Playwright 真实链路，验证偏好抽屉、主题及布局刷新保持、登录三种布局、记住账号隔离、通知空状态、全屏、搜索、锁屏／解锁／退出及清空偏好退出。
- 桌面及窄窗口检查并保存虚构数据截图；结束后停止测试服务，保留日常开发三项服务。
- 文档记录最小底座补丁和功能矩阵。演示站当前版本不作为升级固定底座的理由；在线页面当前无法通过浏览器连接直接核验，不能声称逐像素或全功能等同最新版演示站。
