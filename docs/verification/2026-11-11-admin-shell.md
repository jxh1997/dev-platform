# 2026-11-11 管理后台通用交互验证

本次范围由用户确认：“先恢复前端通用交互，站内消息后端后续再做”。来源保持 Vben Admin v5.7.0。实现依据与最小底座补丁见 [ADR-003](../architecture/ADR-003-admin-shell.md)，没有修改认证接口、权限规则、数据库结构或生产部署。

## 功能范围

| 能力 | 当前行为 |
|---|---|
| 登录页 | 账号密码真实登录，居左／居中／居右布局、主题和偏好入口；窄窗口自动单列 |
| 记住账号 | 可选，仅保存账号；按应用命名空间与 Origin 隔离，取消后移除；不保存密码或 Token |
| 偏好设置 | 修复打开按钮与缓存合并，外观、布局、控件可设置；刷新恢复视觉偏好，保留应用强制的 backend 鉴权模式 |
| 恢复默认／清空 | 重置偏好；清空偏好并调用真实退出，回到登录 |
| 全屏 | 浏览器进入／退出全屏；不支持时禁用并说明，拒绝时反馈；标签页内容最大化独立工作 |
| 消息 | 通知弹层、查看全部和消息中心空状态；没有假通知、红点或不存在的接口调用 |
| 个人菜单 | 本人账号、姓名和角色标识；个人中心、我的会话、修改密码、锁屏和退出 |
| 搜索与标签 | 搜索已授权菜单并导航，标签刷新、内容最大化／还原和更多操作入口 |
| 时区 | 接回现有时区选择组件与现有 Store；不修改业务 UTC 契约 |
| 临时锁屏 | 临时口令锁定、错误反馈、解锁、返回登录真实退出；口令仅在内存，刷新清除，不代替后端认证 |

## 环境与自动验证

Node 24.22.2 / pnpm 10.33.4；专用测试 MySQL 13307，Web 5778 / API 4311；Playwright Chromium。随机创建并清理虚构测试账号与角色，没有使用真实用户密码，没有修改开发库管理员。

| 命令 | 结果 |
|---|---|
| `pnpm exec vitest run packages/@core/preferences/__tests__/preferences.test.ts --environment happy-dom` | 26 项通过；新增缓存恢复与显式应用约束的回归用例，修复前该项失败 |
| `pnpm typecheck` | 通过，Vue 与服务端类型检查 |
| `pnpm lint` | 通过，包含新增 `lint:shell` 对所改应用及底座源文件检查 |
| `pnpm build:web` | 通过，管理后台生产构建 |
| `pnpm check:boundaries` | 通过；静态边界检查不代替真实授权 |
| `pnpm test:e2e` | 6 项通过（3 项既有业务／权限、3 项新增通用交互），真实 API 与 MySQL 链路 |

完整 E2E 6 项通过后，补拍截图时暴露测试对偏好抽屉页签状态的假设；测试已显式切换外观页，不放宽断言。最终单独重跑 3 项通用交互全部通过（47.6s），截图关闭动画并按视口截取，避免截到过渡帧。

新增交互用例覆盖三种登录布局刷新保持、主题、390px 窄窗口无横向溢出、记住／取消账号、密码／Token 不落 localStorage；全屏真实 Fullscreen API、通知空状态、时区弹窗、本人信息、会话导航、搜索、标签刷新／最大化；偏好布局刷新保持与重置、错误锁屏口令／正确解锁、清空偏好退出；工具栏开关刷新保持、快捷锁屏与返回登录。

既有用例继续验证设备台账读写、改密后重新登录、管理员配置角色／用户／菜单、普通账号页面受限及绕过页面调用 API 被拒绝。未重跑 28 组服务端集成与迁移恢复演练：本次没有后端行为或结构变更，已执行真实 API 的浏览器回归。
