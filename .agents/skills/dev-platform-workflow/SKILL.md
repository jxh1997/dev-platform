# DevPlatform 开发工作流

规则来源是 [AI.md](../../../AI.md)，已读则直接执行，不重复加载。领域规范按任务路由读取，不复制整套教程。

- **分级**：AI.md 第 3–4 节。小修直接完成；新模块、跨模块／公共能力扩面、认证授权、会话、契约或结构变化先走计划审批，不能以“修 bug”降级。
- **大改动**：当前 AI 内部审查实际证据、复用、影响和风险，用 [计划模板](../../../docs/templates/ai-task.md) 给出具体步骤与最小充分验证，只输出结论和依据。用户明确确认当前计划后才编码；确认前只读调查和整理计划。实质扩面提交差异再确认，不默认增加审查代理。
- **读取**：先定位，再读相关片段；同版本规范／技能／环境信息复用。UI 按 AI.md 第 12 节选择技能，不默认叠加多个设计流程或加载全部 Vue 教程。
- **验证**：执行 [质量规范](../../../docs/standards/quality-delivery.md#最小充分验证与停止条件)。先定向，再做必要集成／E2E；构建先于浏览器测试，共用测试库的可变夹具不并行。失败定位后只重测受影响范围；必要检查通过即交付。
- **边界**：不以成本为由削弱权限、真库、并发、事务与迁移验证，不弱化断言求绿。不提前宣称通过，不反复复述计划，小任务不额外制造永久报告。
